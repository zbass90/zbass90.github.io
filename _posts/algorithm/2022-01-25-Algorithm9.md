### **Question**

#### description
한 개의 문자열 `s`와 문자 `t`가 주어지면,  
문자열 `s`의 각 문자가 문자 `t`와 떨어진 **최소 거리**를 출력하는 프로그램을 작성하세요.

#### input
첫 번째 줄에 문자열 `s`와 문자 `t`가 주어집니다.  
문자열과 문자는 소문자로만 구성되어 있으며, 문자열의 길이는 100을 넘지 않습니다.

#### output
첫 번째 줄에 문자열 `s`의 각 문자가 문자 `t`와 떨어진 거리를 **순서대로 출력**합니다.

### **Source**

```java
import java.util.Scanner;

public class Main {
  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);

    String s = sc.next();
    char t = sc.next().charAt(0);

    int[] dist = new int[s.length()];
    int p = 1000; // 충분히 큰 수로 초기화

    // 왼쪽 → 오른쪽
    for (int i = 0; i < s.length(); i++) {
      if (s.charAt(i) == t) {
        p = 0;
      } else {
        p++;
      }
      dist[i] = p;
    }

    // 오른쪽 → 왼쪽
    p = 1000;
    for (int i = s.length() - 1; i >= 0; i--) {
      if (s.charAt(i) == t) {
        p = 0;
      } else {
        p++;
        dist[i] = Math.min(dist[i], p);
      }
    }

    for (int d : dist) {
      System.out.print(d + " ");
    }
  }
}
