### **Question**

#### description
현수는 영희에게 알파벳 대문자로 구성된 비밀편지를 매일 컴퓨터를 이용해 보냅니다.  
비밀편지는 현수와 영희가 서로 약속한 **암호**로 구성되어 있습니다.  
알파벳 한 문자마다 `#` 또는 `*`이 **일곱 개**로 구성됩니다.

예) 현수가 `#*****#`을 보냈다면  
1) `#`→1, `*`→0 으로 바꿔 이진수 `1000001`  
2) 2진수 `1000001` → 10진수 `65`  
3) ASCII 65 → 대문자 `A`

또한, 대문자들의 ASCII 번호는 `A=65` … `Z=90` 입니다.

예) 4개의 문자를 신호로 보냄:  
`#****###**#####**#####**##**`  
이를 7자리씩 자르면  
- `#****##` → `C`  
- `#**####` → `O`  
- `#**####` → `O`  
- `#**##**` → `L`  
결과는 `"COOL"`.

#### input
첫 줄: 보낸 문자의 개수 `N`(10을 넘지 않음)  
다음 줄: 문자 개수의 7배 길이의 `#`/`*` 신호 문자열  
(항상 대문자로 해석 가능하다고 가정)

#### output
영희가 해석한 문자열을 출력합니다.

---

### **Example**

| 항목 | 값 |
|:---|:---|
| 입력(1) | `4` |
| 입력(2) | `#****###**#####**#####**##**` |
| 출력 | `COOL` |

### **Source**

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class Main {
  public static void main(String[] args) throws IOException {
    BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    int n = Integer.parseInt(br.readLine().trim());
    String s = br.readLine().trim();

    StringBuilder ans = new StringBuilder(n);

    // 7자리씩 끊어서 #->1, *->0 변환 후 ASCII 해석
    for (int i = 0; i < 7 * n; i += 7) {
      String chunk = s.substring(i, i + 7)
                      .replace('#', '1')
                      .replace('*', '0');
      int code = Integer.parseInt(chunk, 2);
      ans.append((char) code);
    }

    System.out.println(ans.toString());
  }
}
